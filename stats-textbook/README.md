# Statistics: A First Course

A university-level introductory statistics textbook, published as both a static
HTML site and an EPUB. This is a draft edition: **Chapters 1–7** (all of Part I,
Descriptive Statistics & Exploratory Data Analysis, plus the opening chapter of
Part II, Probability) are complete with full text, worked examples, figures, and
exercises with selected solutions. Chapters 8–28 exist as placeholder pages that
name and describe planned content, preserving the full 28-chapter table of
contents for future editions.

## Structure

```
stats-textbook/
  html/               Static HTML edition — start at html/index.html
    index.html        Full table of contents (all 6 parts / 28 chapters)
    ch01-*.html … ch28-*.html
    styles.css
  images/             Raster (PNG) figures, generated by scripts/make_images.py
  epub/
    statistics-a-first-course.epub   EPUB edition (validated with epubcheck)
  scripts/
    make_images.py    Generates all chapter figures with matplotlib
    make_stubs.py      Generates the forthcoming-chapter placeholder pages
    build_epub.py       Packages the HTML chapters + images into the EPUB
```

## Rebuilding

```
pip install -r requirements.txt
python3 scripts/make_images.py   # regenerate figures
python3 scripts/make_stubs.py    # regenerate placeholder chapters
python3 scripts/build_epub.py    # rebuild the .epub from html/ + images/
```

Validate the EPUB with `python3 -c "from epubcheck import EpubCheck; print(EpubCheck('epub/statistics-a-first-course.epub').valid)"`.
